# RR Tech — Sites & Sistemas

Empresa de **sites profissionais** e **sistemas web sob medida**.

Este repositório é o site oficial: identidade da marca (preto, branco, azul `#0060F8`), geometria em corte diagonal e conteúdo em português.

**Sites que marcam. Sistemas que resolvem.**

## O que a empresa faz

- Sites institucionais
- Landing pages
- Interfaces digitais
- Sistemas web sob medida
- Redesign de experiências

Dois clientes já estão em andamento. Os cases entram no ar quando puderem ser publicados.

## Stack do site

TanStack Start · React 19 · Tailwind CSS v4 · Vite · Lenis

## Desenvolvimento

```bash
npm install
npm run dev
```

O app sobe em `http://localhost:8080`.

```bash
npm run typecheck
npm run build
```
